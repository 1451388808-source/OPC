# 决策

这里只记录你已经点头的决定。条目只追加，不改写旧条目，不删除。

README、聊天和任务 `notes` 里的方案都是草案。一条决定要同时满足下面三点，才写到这里：

1. 它改变了以后怎么做：存储方式、阶段、角色职责、目标，或一条会反复用到的取舍。
2. 对应任务的 `status` 已经被你改为 `done`。
3. 该任务的 `decision` 字段有一句人能读的结论。

## 条目格式

```markdown
## YYYY-MM-DD · 用一句话写出决定

- 决定：
- 理由：
- 任务：t-000
```

## 已生效的条目

尚无。`t-001` 还在待批准。你批准并把那个任务标成 `done` 之后，再把第一条追加在这一节下面。
